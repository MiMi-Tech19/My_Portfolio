PORTFOLIO PROJECT - SETUP GUIDE

Project: Miracle Nwachukwu Portfolio

==================================================
1. REQUIREMENTS
==================================================

Before running this project, make sure you have installed:

- Node.js (LTS version recommended)
- npm (included with Node.js)
- Git
- Visual Studio Code (recommended)

To check your installations, run:

node -v
npm -v
git --version

==================================================
2. CLONE THE REPOSITORY
==================================================

Open your terminal and run:

git clone https://github.com/MiMi-Tech19/My_Portfolio.git

Navigate into the project folder:

cd My_Portfolio

==================================================
3. INSTALL DEPENDENCIES
==================================================

Run:

npm install

This installs the dependencies required by the project.

==================================================
4. START THE DEVELOPMENT SERVER
==================================================

Run:

npm run dev

Vite will start the local development server.

Open the URL displayed in your terminal, usually:

http://localhost:5173/

==================================================
5. BUILD FOR PRODUCTION
==================================================

To create an optimized production build, run:

npm run build

The generated production files will be placed in the dist folder.

==================================================
6. RUN CODE QUALITY CHECKS
==================================================

To check the project for linting issues, run:

npm run lint

==================================================
7. DEPLOYMENT
==================================================

This portfolio is deployed using GitHub Pages.

Live website:

https://mimi-tech19.github.io/My_Portfolio/

The project uses GitHub Actions for its deployment workflow.

==================================================
8. USEFUL COMMANDS
==================================================

Install dependencies:
npm install

Start development server:
npm run dev

Build project:
npm run build

Run lint:
npm run lint

Preview production build:
npm run preview

==================================================
END OF SETUP GUIDE
